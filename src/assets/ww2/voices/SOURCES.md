# Radio voice recordings

## Medic request shout

- **File:** `medic-call.wav`
- **Text:** "Medic!"
- **Source:** Synthesized locally with the installed Microsoft David Desktop voice using urgent SSML delivery.
- **Changes:** Trimmed silence, filtered and compressed, normalized, and exported as mono 22.05 kHz PCM. Bundled playback requires no system speech voice.
